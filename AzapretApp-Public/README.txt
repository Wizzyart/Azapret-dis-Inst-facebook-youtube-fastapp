Azapret Public Edition

How to start:
1. Extract the archive to a simple folder, for example C:\Azapret or C:\DIS.
2. Open Azapret.exe.
3. Click Network Check, select the recommended option, then click Start.

Important:
- Close/minimize sends Azapret to the tray near the clock.
- To fully exit, right-click the tray icon and choose Exit.
- Autostart is off by default. Enable it only if you want Azapret to start with Windows.
- All internal files are in app\. Regular users should start only Azapret.exe.

If something does not work:
- Restart the browser tab or the browser after pressing Start.
- Try Network Check again and choose another option.
- Use the Stop button before trying another option.
- If Windows shows SmartScreen, choose More info, then Run anyway only if you trust this package source.
