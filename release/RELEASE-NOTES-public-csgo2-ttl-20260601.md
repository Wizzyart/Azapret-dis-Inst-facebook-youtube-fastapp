Azapret Discord / YouTube / CSGO2 TTL для Windows.

## Как пользоваться CSGO2 / FACEIT / CS2 TTL

1. Оставьте обычный обход Discord/YouTube в автостарте, например `ALT11`.
2. Откройте Azapret и перейдите в `Сервисные действия`.
3. Нажмите `CS/Faceit check`.
4. Введите IP сервера CS/FACEIT в формате `IP:PORT`.
5. Нажмите `Проверить IP по всем TTL`.
6. В журнале и popup появится рекомендованный `FACEIT CS2 TTLx`.
7. Выберите рекомендованный TTL и нажмите `Запустить выбранный TTL`.
8. После игры нажмите `Стоп TTL` или `Стоп FACEIT TTL`.

Важно:
- FACEIT TTL запускается вместе с основным обходом Discord/YouTube.
- Автостарт службы не переписывается.
- `Стоп FACEIT TTL` останавливает только игровой TTL-процесс.
- Проверка IP выбирает TTL по ping/loss до указанного сервера, но итог всё равно нужно подтвердить в игре.

## Возможности

- удобный Windows-лаунчер;
- проверка сети и подбор обхода;
- ручной Старт/Стоп;
- Автостарт через службу Windows;
- СТОП ВСЕ;
- IPSet фильтр;
- игровой TCP/UDP фильтр;
- CSGO2 / FACEIT / CS2 TTL-профили;
- проверка IP сервера по всем FACEIT TTL;
- запуск FACEIT TTL совместно с основным Discord/YouTube обходом;
- отдельная остановка `Стоп FACEIT TTL` без отключения основного обхода;
- обновление IPSet;
- фикс Instagram/Facebook;
- Telegram proxy-инструкция;
- русскоязычный интерфейс.
